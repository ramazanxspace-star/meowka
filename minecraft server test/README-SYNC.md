# Origins Neverland - Рабочая папка

Эта папка содержит полную копию тестового сервера `C:\Users\1R\Documents\minecraft server test` для разработки и тестирования.

**ВАЖНО**: 
- Все изменения делайте ТОЛЬКО в этой папке (`neverland/`)
- Эта папка содержит полную копию тестового сервера
- Изменения синхронизируются в обе стороны с тестовым сервером

## Автоматическая синхронизация

### Синхронизация изменений НА тестовый сервер
Для компиляции и копирования плагина на тестовый сервер используйте:

```bash
sync-to-server.bat
```

Этот скрипт:
1. Компилирует проект (mvn clean package)
2. Копирует готовый JAR файл в `C:\Users\1R\Documents\minecraft server test\plugins\`
3. Показывает статус операции

### Синхронизация изменений С тестового сервера
Для копирования изменений с тестового сервера используйте:

```bash
sync-from-server.bat
```

Этот скрипт:
1. Копирует все изменения с тестового сервера в папку `neverland/`
2. Исключает большие файлы (логи, миры, кэш)
3. Показывает статус операции

## Ручная синхронизация

Если автоматический скрипт не работает, выполните команды вручную:

```bash
# Компиляция
mvn clean package

# Копирование
copy "target\origins-neverland-1.0-SNAPSHOT.jar" "C:\Users\1R\Documents\minecraft server test\plugins\"
```

## Рабочий процесс

### Для разработки плагинов:
1. **Разработка**: Все изменения делайте в этой папке (`neverland/`)
2. **Компиляция и синхронизация**: Запустите `sync-to-server.bat`
3. **Тестирование**: Перезапустите тестовый сервер `C:\Users\1R\Documents\minecraft server test`
4. **Проверка**: В игре используйте `/origins choose neverland_creature`

### Для синхронизации изменений с сервера:
1. **Получение изменений**: Запустите `sync-from-server.bat`
2. **Проверка**: Убедитесь, что изменения скопированы
3. **Разработка**: Продолжайте работу с обновленными файлами

## Важно

- ✅ Все изменения делайте в этой папке (`neverland/`)
- ✅ После изменений запускайте `sync-to-server.bat`
- ✅ Не забудьте перезапустить тестовый сервер после обновления плагина
- ❌ НЕ редактируйте файлы в основной папке проекта
